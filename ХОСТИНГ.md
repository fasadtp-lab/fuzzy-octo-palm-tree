# Куда положить тур, чтобы ссылка открывалась в России

Сайт — это четыре файла из папки `docs/`: `index.html`, `three.min.js`,
`video.mp4`, `poster.jpg`. Никакого сервера, базы и сборки не нужно: любой
хостинг, который умеет отдавать статические файлы, подойдёт.
Готовый архив со всеми четырьмя — `dist/kvartira-643-site.zip`.

## Вариант 1. Без хостинга вообще — один файл

`dist/kvartira-643-3d-tour.html` (780 КБ) — весь тур в одном файле, включая
библиотеку рендера и шрифты. Открывается двойным кликом, работает без
интернета. Можно отправить клиенту в WhatsApp или Telegram как документ:
на компьютере откроется сразу, на Android — через браузер из файлового
менеджера, на iPhone — из «Файлов» через «Поделиться → Safari».

Видеообзор в этот файл не вшит, он идёт отдельным `video.mp4`.

## Вариант 2. Российский хостинг (рекомендую для постоянной ссылки)

### Yandex Object Storage

1. console.yandex.cloud → Object Storage → создать бакет,
   публичный доступ на чтение объектов.
2. Загрузить четыре файла из `docs/`.
3. В настройках бакета: «Веб-сайт» → главная страница `index.html` → Сохранить.
4. Ссылка вида `https://<имя-бакета>.website.yandexcloud.net`.

Стоит копейки: 10 МБ хранения и трафик на несколько сотен просмотров —
рубли в месяц. Домены Яндекса в России не блокируются.

### Обычный хостинг сайта компании (если он уже есть)

Залить папку `docs/` по FTP в подпапку сайта, например `/tur-643/`, —
ссылка станет `https://ваш-сайт.ру/tur-643/`. Это самый предсказуемый
вариант: домен ваш, блокировок нет, ничего настраивать не надо.

### Timeweb Cloud, Beget, Selectel

В панели есть раздел «Статический сайт» / «Хостинг»: создать сайт,
загрузить архив, распаковать. Все три — российские дата-центры.

## Вариант 3. GitHub Pages

Бесплатно и без настройки сервера: Settings → Pages → Deploy from a branch →
`main` → `/docs` → Save. Ссылка `https://fasadtp-lab.github.io/fuzzy-octo-palm-tree/`.
Сам GitHub в России работает, но у отдельных провайдеров домен `github.io`
периодически недоступен, поэтому как основную ссылку для клиентов лучше
брать вариант 2.

## Если ссылка не открывается — что проверить

1. Включены ли Pages вообще: Settings → Pages. Если раздел пустой, сайт
   не опубликован и ссылка будет отдавать 404 у всех.
2. Влит ли PR в ветку, с которой раздаётся сайт.
3. Прошла ли минута после включения — первая сборка занимает до 60 секунд.
4. Открывается ли ссылка с мобильного интернета другого оператора — так
   отличают блокировку провайдером от отсутствия сайта.
