# Видеообзор квартиры № 643

Рендер видео из того же 3D-тура (`../3d-tour/index.html`): та же сцена, но с
кинематографичным проходом камеры, титрами и заставками. Ничего не снимается
с экрана вручную — кадры считаются в headless-Chromium и сразу уходят в ffmpeg.

## Как пересобрать

```bash
cd video
npm i                     # three.js, ffmpeg (h264), шрифты Manrope/Unbounded
python3 make-tour.py      # собирает tour.html из 3d-tour/index.html + оверлей
node render.mjs           # рендер всех кадров → tour-643.mp4 (~1 ч на 4 ядрах)
node render.mjs --stills 300,900,1500   # отдельные кадры для проверки ракурсов
```

Готовый `tour-643.mp4` в репозиторий не коммитится — это артефакт сборки.
Публикуемая копия лежит в `docs/video.mp4` и уезжает на GitHub Pages вместе
с туром; `shot-page.mjs` — вспомогательный скрипт, снимает скриншот любой
страницы в headless-Chromium (проверка вёрстки на телефоне и на десктопе).

## Из чего состоит

| Файл | Назначение |
|---|---|
| `make-tour.py` | собирает `tour.html`: подключает локальный three.js, прячет интерфейс тура, добавляет титры, заставку и финальную плашку, вшивает шрифты в base64 |
| `cinema.js` | раскадровка: массив `SHOTS` (откуда/куда идёт камера, куда смотрит, титр, склейка) и функция `__frame(i)` — кадр считается по номеру, а не по времени |
| `render.mjs` | запускает Chromium с программным WebGL, по одному кадру гонит `__frame(i)` → `Page.captureScreenshot` → stdin ffmpeg |

## Параметры

- 1280×720, 30 кадров/с, H.264, звука нет;
- 12 планов общей длительностью 79 с;
- широкий угол 80° — стандарт для съёмки интерьеров;
- тень от солнца считается один раз (`shadow.autoUpdate = false`), солнце статично.

Чтобы изменить маршрут камеры или тексты — правьте `SHOTS` в `cinema.js`
и пересоберите. Координаты те же, что в плане квартиры (см. `../3d-tour/README.md`).
