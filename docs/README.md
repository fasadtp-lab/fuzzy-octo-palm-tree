# Публичная версия 3D-тура

Содержимое этой папки — то, что отдаётся посетителю по ссылке:
`https://fasadtp-lab.github.io/fuzzy-octo-palm-tree/`

- `index.html` — весь тур одним файлом: разметка, стили, шрифты (вшиты в base64) и сцена;
- `three.min.js` — библиотека рендера, лежит рядом, внешних CDN нет;
- `poster.jpg` — картинка для превью ссылки в мессенджерах;
- `video.mp4` — видеообзор (появляется после сборки видео);
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

Папка собирается из исходника, руками её править не нужно:

```bash
cd 3d-tour && python3 build-public.py
```

Как включить публикацию: **Settings → Pages → Source: Deploy from a branch →
ветка `main`, папка `/docs` → Save.** Через минуту ссылка заработает.
