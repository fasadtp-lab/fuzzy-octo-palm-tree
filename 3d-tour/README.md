# 3D-тур по квартире № 643 (39,30 м², ул. Родины)

Один самодостаточный файл `index.html`: прогулка от первого лица по квартире
с готовым ремонтом. Внешних ассетов нет — все текстуры (обои, ламинат,
керамогранит, камень, ковёр, небо) рисуются на canvas при запуске.
Библиотека three.js подгружается с CDN (cdnjs, запасной вариант — jsdelivr).

## Планировка

Построена по чертежу № 643. Оси: `x` — вправо по плану, `z` — вниз (от входной
двери к фасаду), `y` — вверх. Внутренний габарит 0,125…6,395 × 0,125…6,445 м,
потолок 2,70 м.

| Помещение | Площадь по плану | Прямоугольник (x0, z0, x1, z1) |
|---|---|---|
| Прихожая | 5,80 м² | 1,975 · 0,125 · 4,205 · 2,575 |
| Санузел | 4,50 м² | 0,125 · 0,125 · 1,855 · 2,575 |
| Кухня-гостиная | 17,70 м² | Г-образная: 4,325 · 0,125 · 6,395 · 2,575 + 3,305 · 2,575 · 6,395 · 6,445 |
| Спальня | 11,30 м² | 0,125 · 2,695 · 3,185 · 6,445 |

Проёмы и окна — из чертежа: входная дверь 1100 мм, окно спальни 1570 мм,
окно кухни-гостиной 1830 мм, проёмы в санузел и в спальню по 800 мм,
проём из прихожей в кухню-гостиную 800 мм. Межкомнатных дверей нет —
все три проёма оформлены открытыми арками высотой 2,10 м.

## Отделка

- стены — светлые телесные обои;
- пол — тёмный ламинат (планка 190 мм), в санузле бежевый керамогранит 600×600;
- оконные рамы и обрамление арок — белые;
- кухня — белый угловой гарнитур 1,47 + 1,93 м с тёмной каменной столешницей,
  фартук из того же керамогранита, техника в нержавеющей стали;
- акценты — дуб (столешницы, стол, тумбы), оливковый и терракотовый текстиль,
  живые цветы в каждом помещении.

## Как править

Всё описано данными в начале `<script>`:

- `PLAN` — габариты и толщины стен;
- `WALLS` — стены с проёмами (`kind`: `door` — проход, `window` — остекление,
  `fixed` — закрытая дверь);
- `DOORS` — только входная дверь; `ARCHES` — межкомнатные проёмы без полотен;
- `ROOMS` — комнаты для мини-карты, подписей и кнопок-телепортов.

Мебель каждой комнаты — в функциях `buildHall`, `buildBath`, `buildLiving`,
`buildBedroom`.

## Управление

`W A S D` / стрелки — идти, мышь — осмотреться, `Shift` — бегом, `C` — присесть,
`M` — план, `L` — день/вечер, `Esc` — выйти из обзора. На телефоне — джойстик
слева и свайп для обзора.
